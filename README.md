# Kita · Starship web deck

An English HTML slide deck (19 slides) about the development of SpaceX's Starship: why it matters, how it works, the test-flight timeline up to the first orbital flight (Sept. 28, 2026), official timelines, the businesses built on it, and the Moon and Mars vision. It is meant for classrooms and general audiences.

- `index.html`: the deck. Use the arrow keys, Space, a click, or a swipe to move. F = fullscreen, N = speaker notes, P = presenter view.
- `style.css` and `deck.js`: the styles, the navigation, and the animated starfield.
- `assets/photos/`: real photos from Wikimedia Commons (CC BY 2.0, CC BY-SA 4.0, or public domain). Credits are on the Sources slide.
- `assets/concepts/`: concept illustrations of future ideas. They are labeled on each slide.

Static site with no build step. Vercel auto-deploys it from `main`. Facts were checked on Oct. 10, 2026. Made by Kita.
